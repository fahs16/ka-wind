Lihat Undangan Rekap RSVP
Undangan sedang dikunci (access.private: true di js/config.js). Artinya hanya kode yang ada di js/guests.js yang bisa membuka undangan — pengunjung lain cuma melihat gambar gerbang terkunci. Jadi setelah membuat daftar di bawah, wajib unduh js/guests.js dan unggah ulang situsnya. Kalau tidak, tamu kamu ikut terkunci.

Halaman ini cuma buat kamu, bukan buat tamu. Ketik daftar tamunya, nanti keluar link personal per orang + teks siap kirim WhatsApp. Semua diproses di browser ini, tidak ada data yang dikirim ke mana pun.

Format: Nama | jumlah kursi | grup | nomor WA. Kolom setelah nama boleh dikosongkan, contoh: Pak Budi atau Pak Budi | 2. Nomor WA pakai format 628xxx.

Kode yang bisa dipakai: {nama}, {link}, {kursi}, {mempelai}, {tanggal}.

Isi file js/guests.js

Salin blok di bawah ini, timpa isi file js/guests.js, lalu unggah ulang situsnya. Tanpa langkah ini, link ?u=kode belum mengenali nama tamu.
